# dsh-market-groups

[English](README.md) · **简体中文**

DSH 插件市场（`dshmarket`）的客户端增强层。不修改市场本身：只观察页面、追加装饰，并复用市场已有的
HTTP 接口。

## 做什么

| 功能 | 效果 |
| --- | --- |
| 冲突高亮 | 有冲突的插件行会出现彩色左边条和 `冲突` / `同依赖` 徽标；鼠标悬停任意一行，与它冲突的所有行同时高亮。 |
| 按类别分组 | 「新建分组」旁多一个 **按类别分组** 按钮，把还没分组的已装插件按市场自带的 23 个类别归组。 |
| 默认分组视图 | 每次打开已安装列表都自动切到分组视图；`未分组` 改名为 `通用`。 |
| 首次自动铺组 | 整个 profile 一个分组都没有、且已装插件多于 3 个时，自动分类一次并刷新。 |

冲突来源全部来自市场自己的 `/dsh-market/check`：

- 硬（`冲突`）：cordis 条目 id 重复、多版本共存、peer 版本不满足、加载顺序冲突
- 软（`同依赖`）：两个插件各自带了一份同名依赖

## 开关

| 键 | 默认 | 含义 |
| --- | --- | --- |
| `localStorage['dshm:include-theme'] = '1'` | 关 | 把 `theme` 类插件也归入「主题与外观」（默认留在 `通用`）。 |
| `localStorage['dshm:auto-classified:v1'] = '1'` | 未设 | 标记一次性自动分类已完成。 |
| URL `?dshm-demo=conflicts` | 关 | 给前 4 个已装插件注入假冲突，用来验证高亮管线。 |

## 安装

像其他 bundle 一样把它加进 DSH profile（插件管理或市场条目）。开发时用指向本目录的 `link:` 依赖也可以。
宿主侧是空壳，逻辑全在 `client/client.js`。

## 市场改版怎么办

选择器和按钮文案都集中在 `client/client.js` 顶部（`ROWS_SELECTORS`、`NAME`、`TEXT_GROUPS`、
`TEXT_NEW_GROUP`）。市场换了 DOM，只改这几个常量。面板挂上了却匹配不到任何插件行时，会在控制台打一条
警告，而不是静默失败。
